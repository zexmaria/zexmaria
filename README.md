# Hi there, I'm José Maria 👋

### 🧑‍💻 About Me

Backend developer with a strong focus on Python and Django, building complete and production-ready web systems. My main project is a full-featured **e-commerce platform for musical instruments** — covering product catalog, session cart, checkout, order management, async task processing, fiscal document emission (NF-e), and an advanced admin panel.

I work across the full stack: from server-side architecture and database design to async workers, CI/CD pipelines, security hardening, and third-party API integrations (payments, shipping, analytics, AI).

### 📌 Featured Project

**[loja-instrumentos](https://github.com/zexmaria/loja-instrumentos)** — Full e-commerce for musical instruments built with Django, HTMX, TailwindCSS and Jazzmin. Features browsable catalog by category and brand, session-based cart, user authentication with login history, order management, async background tasks (Celery + Redis), S3 media storage, NF-e fiscal document emission, payment and shipping API integrations, and a complete admin panel.
